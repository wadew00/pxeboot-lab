# Public boot tree

This directory contains the small, public files used by the persistent iPXE
client. Installer payloads are fetched directly from their upstream mirrors and
are not stored in GitHub.

The current selected target is the Fedora 44 Server installer. Anaconda runs
its interactive graphical installer over RDP; SSH is available only as a
temporary maintenance/log shell and accepts the public key in `fedora.ks`.

RDP credentials are generated by iPXE at boot:

```text
address:  <the HP's router DHCP address>:3389
username: installer
password: pxe-<Ethernet MAC written with hyphens>
```

This password protects only the temporary installer on the local LAN and is
not intended to be a reusable secret. Installation and disk choices remain
interactive; this Kickstart does not partition or install automatically.

Boot URL:

```text
https://raw.githubusercontent.com/wadew00/pxeboot-lab/main/public/boot.ipxe
```
