# Public boot tree

This directory contains the small, public files used by the persistent iPXE
client. Installer payloads are fetched directly from their upstream mirrors and
are not stored in GitHub.

The current selected target installs the Fedora 44 Workstation desktop from
the official Everything network-install tree. Anaconda runs its interactive
installer over RDP. The installed Workstation keeps OpenSSH and GNOME Remote
Desktop available; the public key in `fedora.ks` authorizes root SSH access.

RDP credentials are generated by iPXE at boot:

```text
address:  <the HP's router DHCP address>:3389
username: installer
password: pxe-<Ethernet MAC written with hyphens>
```

This password protects only the temporary installer on the local LAN and is
not intended to be a reusable secret. Installation and disk choices remain
interactive; this Kickstart selects Fedora Workstation packages and the
graphical boot target, but does not partition or start installation
automatically.

After the first installed-system boot, use SSH once to choose separate GNOME
Remote Login gateway credentials and enable its native system RDP service:

```sh
ssh root@CLIENT_IP
grdctl --system rdp set-credentials REMOTE_USER 'A-NEW-STRONG-PASSWORD'
grdctl --system rdp enable
systemctl enable --now gnome-remote-desktop.service
```

Then connect the Mac RDP client to `CLIENT_IP:3389` and log into the normal
GNOME desktop. The Kickstart opens TCP 3389 in Fedora's firewall; no router port
forward is needed on the same LAN.
